PERSONAL BACKUP CONNECTION

TouTou Drive Backup

A personal Google Drive backup connection operated by its account owner using rclone on his own computer.

Its purpose is to copy Google Drive files to a local hard drive and periodically download new or changed files. Google documents may be exported into offline file formats. The connection requests read-only access to file contents and metadata; it does not request permission to edit or delete files in Google Drive.

Privacy policy

Effective date: 6 November 2026.

Access and purpose

The backup connection accesses file names, folder structure, file metadata and file contents solely to make and update the account owner's local backup. It is for the owner's personal use, not a service offered to other users.

Storage and sharing

Downloaded files are stored on storage selected by the owner. OAuth credentials and tokens are kept in the owner's local rclone configuration and must not be published. This website and its public GitHub repository do not receive Google Drive files, metadata, credentials or tokens. The backup connection does not sell Google user data, use it for advertising, or use it to train AI models. Transfers between Google and the local computer are performed by rclone.

Retention and control

Local backups remain until the owner deletes them. Deleting a file in Google Drive may not delete its local backup or retained versions. Access can be revoked in the Google Account's third-party connections settings. Revoking access stops future authorized access but does not remove existing local copies.

Website hosting

This static information page has no sign-in, forms, analytics scripts or advertising. GitHub Pages hosts it and may process visitor information such as IP addresses under GitHub's privacy statement.

Google API use

TouTou Drive Backup's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Support is provided directly by the owner; the support email is displayed on the Google consent screen.

Terms of use

This is a personal backup configuration, not a public backup service. The owner controls its operation, destination storage and retention. Backup completeness and recoverability should be checked; no guarantee of uninterrupted operation or recovery is made. Google and rclone are separate products of their respective providers.
